# STOREEX

STOREEX is a business management, invoicing, POS and warehouse system built with classic ASP.NET MVC 5 (.NET Framework), Entity Framework 6 and SQL Server.

## Planned modules

- Premium responsive dashboard
- ASP.NET Identity login and roles (Admin, Manager, Cashier, Warehouse)
- Products, categories and units
- Customers and suppliers
- Sales invoices, invoice items and payments
- Advanced POS with barcode workflow
- Warehouses, warehouse stock, movements, adjustments and transfers
- Purchases and receiving
- Expenses
- Reports and analytics
- Multi-company data model
- Audit log and application settings
- Kendo UI grids/charts integration

## Technology

- ASP.NET MVC 5 / .NET Framework 4.8 (not ASP.NET Core)
- Entity Framework 6
- SQL Server / LocalDB for development
- ASP.NET Identity 2
- Bootstrap + custom STOREEX premium UI
- Kendo UI integration points (licensed Telerik assets are not committed)
